# Budget Tracker

A personal finance tracking application designed to help users manage their income, expenses, savings, and budgets.

The long-term goal is to provide a clear overview of personal finances, including support for multiple currencies.

## Project Roadmap

### Phase 1 - Local Web Application

- React
- TypeScript
- Vite
- Tailwind CSS
- LocalStorage
- Vitest
- ESLint
- Prettier

### Phase 2 - Backend and Cloud Integration

- Python
- Django
- Django REST Framework
- PostgreSQL
- User authentication and authorization
- REST API

### Phase 3 - Desktop and Mobile Applications

- Tauri for desktop
- Capacitor for mobile

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/kok1ng/budget-tracker.git
cd budget-tracker
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev -- --host 127.0.0.1
```

Open the local address displayed in the terminal.

## Available Commands

| Command                           | Description                      |
